仓库结构

路径说明
package/cms主程序，需 chmod +x 后由 systemd 拉起
package/html/Web 静态资源，必须与 cms 同级
package/data/运行数据目录（含模板；空目录会在运行/安装时生成内容）
package/config.example.json配置模板，复制为 config.conf 后填写数据库信息
package/iycms.servicesystemd 服务单元样例
docs/本 GitHub Pages 文档站
checksums.sha256归档包与关键文件的 SHA256 校验值

备份说明

备份来自一台正在运行的 IYCMS 2.3.4 实例，打包时做了脱敏与瘦身：

项目处理方式
数据库连接配置移除真实密码，改为 config.example.json 占位模板
install.lock不收录（安装状态与实例绑定，重新安装会生成）
data/key/、data/token/不收录（实例授权/令牌数据）
data/cache/、data/uploadFile/、data/app/不收录（缓存、用户上传与 134MB 安卓/iOS 安装包）
stdout.log不收录（原文件约 802MB）
